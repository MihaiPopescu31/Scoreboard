# 🏀 COURTSIDE – Basketball Scoreboard

An interactive basketball scoreboard built with **HTML5, CSS3 and Vanilla JavaScript**, based on a custom Figma design.

## Features

- Dynamic score tracking (+1, +2, +3 points).
- Leading team indicator.
- 10-minute countdown timer (Start / Pause).
- Game period management (1–4).
- New Game functionality (reset scores and timer).

## Key Concepts & Skills

- **DOM Manipulation:** Selecting and updating HTML elements.
- **Event Handling:** Managing user interactions with `addEventListener()`.
- **JavaScript Logic:** Variables, functions, conditional statements and loops.
- **Array Iteration:** Using `forEach()` to handle score buttons.
- **Data Attributes:** Reading button values using `dataset`.
- **Timer Functions:** Implementing countdown logic with `setInterval()` and `clearInterval()`.
- **UI Updates:** Dynamically rendering scores and game status.
